## 1. Назначение программы

Программа предназначена для просмотра, анализа и визуализации данных о рынке
криптовалют. Она поддерживает работу с учётной записью, получение актуальных
курсов через интернет, формирование аналитических отчётов и ленту новостей.

Программа работает и без подключения к интернету: при отсутствии сети
используются ранее сохранённые данные.

---

## 2. Структура папок

После распаковки вы увидите следующее:

```
Проект/
├── scripts/           ← программные модули и точки входа
│   ├── main.py        ← запуск приложения (python scripts/main.py)
│   ├── news_server.py ← запуск сервера новостей (по желанию)
│   └── ...            ← остальные модули
├── database/          ← все данные: основная база, аккаунты, новости
├── graphics/          ← сохранённые графические отчёты
├── output/            ← сохранённые текстовые отчёты
├── docs/              ← руководства пользователя и разработчика
└── requirements.txt   ← список библиотек
```

Все ваши данные (учётные записи, избранное, новости, настройки) хранятся в
папке **database/**. Чтобы перенести программу на другой компьютер вместе со
всеми данными, скопируйте папку целиком.

## 3. Первый запуск

1. Откройте терминал в папке проекта и выполните:
   ```
   python scripts/main.py
   ```
2. При **первом** запуске откроется окно **регистрации**. Придумайте логин
   (не менее 3 символов) и пароль (не менее 4 символов) и нажмите
   «Зарегистрироваться».
3. В дальнейшем при запуске будет появляться окно **входа**. Введите логин и
   пароль. Программа запоминает вход — при следующем открытии вы сразу
   попадёте в главное окно.

> Ваш пароль хранится в защищённом виде и нигде не отображается в открытом
> тексте.

### Запуск через Anaconda

Если у вас установлен **Anaconda**, удобно создать отдельное окружение:

1. Откройте **Anaconda Prompt** (Windows) или терминал (Linux/macOS).
2. Перейдите в папку проекта:

   ```
   cd путь/к/папке/проекта
   ```

3. Создайте и активируйте окружение, установите библиотеки:

   ```
   conda create -n crypto python=3.12
   conda activate crypto
   conda install -c conda-forge pandas numpy matplotlib openpyxl
   ```

4. Запустите приложение:

   ```
   python scripts/main.py
   ```

В дальнейшем достаточно `conda activate crypto` и `python scripts/main.py`.
Графическая библиотека (tkinter) входит в Anaconda, отдельно её ставить не
нужно.

## 4. Главное окно

В верхней части окна расположены:

- **Имя пользователя** (слева) — щелчок по нему открывает личный кабинет.
- **Переключатель темы** — смена светлого и тёмного оформления.
- **Кнопка выхода** — завершение сеанса и возврат к окну входа.

Ниже находятся вкладки.

### Вкладка «Данные»
Таблица торговых данных. Кнопка **«Обновить (API)»** загружает актуальные
курсы из интернета. После обновления появляется уведомление с источником
данных:

- **реальное время** — данные получены из интернета;
- **кеш** — интернет недоступен, показаны сохранённые ранее данные;
- **локальная база** — используются исходные данные программы.

### Вкладки отчётов
Текстовые отчёты (выборка сделок, частотный анализ, статистики, сводная
таблица). Задайте параметры и нажмите кнопку формирования — результат
появится в таблице. Отчёт можно сохранить в файл (папка **output/**).

### Вкладки диаграмм
Графические отчёты шести типов:

- **Линейный график** — динамика показателя во времени по группам.
- **Кластеризованная столбчатая** — сравнение значений по двум атрибутам.
- **Гистограмма** — распределение количественного атрибута по категориям.
- **Ящик с усами** — разброс значений по группам.
- **Диаграмма рассеяния** — связь двух количественных переменных.
- **Круговая (кольцевая)** — доли атрибута.

Диаграмму можно сохранить как изображение (папка **graphics/**).

### Вкладка «Новости»
Лента новостей. Можно опубликовать новость и обновить ленту с сервера
(см. раздел 6).

## 5. Личный кабинет

Открывается щелчком по имени пользователя вверху. Здесь можно:

- **Изменить аватар** — выбрать изображение (формат PNG или GIF).
- **Заполнить личные данные** — ФИО, дату рождения, телефон, страну.
- **Просмотреть статус верификации (KYC)** — поле только для чтения;
  устанавливается администратором.
- **Управлять избранным** — список отслеживаемых криптовалют и бирж.

Изменения сохраняются автоматически.

---

## 6. Новости (работа с сервером)

Лента новостей может работать в двух режимах:

- **Локально** — новости сохраняются только на вашем компьютере.
- **С сервером** — новости публикуются на общий сервер и доступны всем
  подключённым пользователям.

Чтобы подключиться к серверу:

1. Перейдите на вкладку **«Новости»**.
2. Нажмите **«Указать сервер»**.
3. Введите адрес, который вам сообщил администратор сервера, например
   `http://192.168.1.50:8765`. Чтобы вернуться к локальному режиму, оставьте
   поле пустым.

После этого:

- **«Опубликовать»** — отправляет новость на сервер и сохраняет локально;
- **«Обновить с сервера»** — загружает общие новости.

Если сервер недоступен, программа продолжит работу с локальной лентой.

## 7. Темы оформления

Кнопка переключения темы вверху меняет оформление между светлым и тёмным.
Выбранная тема запоминается и применяется при следующем запуске.

## 8. Частые вопросы

**Программа не открывается, окно не появляется.**
Убедитесь, что установлен Python и необходимые библиотеки (см. раздел
«Установка» в руководстве разработчика), а также что запуск выполняется на
компьютере с графическим рабочим столом.

**При обновлении курсов показывается «кеш» или «локальная база».**
Это значит, что нет доступа к интернету. Программа работает на сохранённых
данных — это штатный режим.

**Я забыл пароль.**
Восстановление пароля не предусмотрено. Обратитесь к администратору —
учётные записи хранятся в файле `database/users_db.xlsx`.

**Как перенести программу с данными на другой компьютер.**
Скопируйте всю папку проекта целиком, включая папку `database/`.
